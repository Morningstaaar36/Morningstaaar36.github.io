What I work with

Each tool below is explained in plain words, followed by where I actually used it.

GPUs and low-level code

CUDA
Code that runs on an NVIDIA graphics card, which can do thousands of small calculations at the same moment. I wrote a search engine for it from scratch, and my rewrite ran up to 44 times faster than my first version.
C++
A fast language that gives you control over memory. I used it for the GPU search engine and for an assembler that turns MIPS assembly into machine code.
C for microcontrollers
Small programs that run directly on a chip. I used it on an ATmega32 to run the motors and sensors of a robot car.
Assembly and digital logic
The instructions a processor really runs. I wrote 8086 programs and built a MIPS processor from logic gates in Logisim.

AI and machine learning

LLMs (large language models)
Programs like Llama that read and write text. I used them to read operator notes, judge science claims and answer questions about city data, and I check what they say instead of trusting it.
AI agents with LangChain
An LLM that picks which tool to call, such as a map lookup or a database query, and answers from the results. NagorMind's agent has 13 tools.
RAG (retrieval-augmented generation)
Look up the right documents first, then let the model answer from them. I used it in the science claim checker and in TeamSync's AI assistant, with the Qdrant vector database.
PyTorch and PyTorch Geometric
Libraries for building and training neural networks, including networks that work on graphs. I used them for molecule toxicity prediction and for fair adaptation of graph models.
Multimodal learning
One model that uses two kinds of input together. SACA-Tox sees a molecule both as a graph of atoms and as a line of text, and combines the two.
Embeddings and re-ranking
Turning text into numbers so similar meanings sit close together, then double-checking the best matches with a slower, more accurate model.

Backend and data

Java Spring Boot
A Java framework for web services. TeamSync and the moderation platform are built from several small Spring Boot services that call each other.
Microservices
Splitting a big app into small services that each do one job. I designed TeamSync's split into gateway, login, tasks, messages and notifications.
Kafka
A message pipe that lets services announce "this happened" without waiting for each other. TeamSync uses it, with Schema Registry, to pass events between services.
FastAPI
A quick way to build web APIs in Python. It runs GridWise and TeamSync's AI backend.
Django and PostgreSQL
A Python web framework with a database that does the heavy lifting. They power UniWorld Gateway.
Node.js, WebSockets and Redis
A JavaScript server, live two-way connections, and a fast memory cache. I used them for NagorMind's server and for TeamSync's live messages and notifications.

Shipping and testing

Docker
Packs an app and everything it needs into one container so it runs the same on any machine. I packaged GridWise as a Docker image, and I set up TeamSync's shared Docker network and deployment scripts.
Azure Container Apps
Runs a container in the cloud and gives it a public address. GridWise is live there.
CI/CD
Tests and ships code automatically when it is pushed. I set this up for TeamSync.
Testing and evaluation
Measuring honestly. The GPU search has 9 CUDA test suites, and GridWise has an evaluation harness that scores it on example cases.

Science and maths

Quantum chemistry with VQE
A quantum-circuit method for estimating a molecule's energy. We checked every result against the exact answer, using CUDA-Q, and ran one on a real IBM quantum computer.
Optimization
Finding the cheapest plan that follows all the rules. GridWise's power schedule is solved with HiGHS through SciPy.
Interpolation
Rebuilding a smooth curve from a few measurements, using polynomials and splines, and choosing the degree from error on points the fit never saw.

AI you can check

A language model can sound sure and still be wrong. These projects make it show its work.

Science claim checker

  • CUDA
  • C++17
  • Llama 3.2
  • ONNX Runtime
  • RAG

Type a science claim, such as "bariatric surgery helps mental health". The program finds the most relevant research papers, has an AI read them, and answers Supported, Contradicted or Not enough info.

It explains its answer with quotes, then automatically checks that every quote really appears in the paper. Finding the papers among 5,183 abstracts takes under a tenth of a millisecond, because the search runs on the GPU.

GridWise

  • Python
  • FastAPI
  • LLMs
  • SciPy
  • Docker
  • Azure

A campus has solar panels, a battery and the power grid. The operator leaves notes like "we'll clean the solar panels from noon to 2 PM". GridWise decides which notes change the plan and builds the cheapest power schedule for the day, then double-checks its own plan.

Built for the BUP CSE Fest 2026 preliminary. I built the AI part, the web service, the tests that score it, and the deployment. It runs live.

NagorMind

  • Node.js
  • LangChain
  • Llama 3.3 70B
  • WebSockets
  • Redis

Ask a question about a Dhaka neighbourhood, such as how well its hospitals cover the people living nearby. An AI assistant chooses from 13 tools covering maps, air quality, weather, planning rules and public spending records, gathers the facts and shows them on a map. It can also check whether money spent on a drain, clinic or road shows up in real life.

Built at the Impact Dhaka Hackathon. I wrote the backend, the agent, the 13 tools and the data layer.

Molecules on a quantum computer

  • Python
  • VQE
  • CUDA-Q
  • IBM Quantum
  • Interpolation

A molecule's energy changes as its atoms stretch or bend. We estimated that energy for eleven molecules with a quantum method, checked every answer against the exact one, and rebuilt whole curves from just a few points. One run used a real IBM quantum computer.

CSE 402 course project. I did BeH₂ and O₂, including a 110-point map of energy against bond length and bond angle, plus the curve fitting and the IBM run.

SACA-Tox

  • Python
  • PyTorch
  • Graph neural network
  • ChemBERTa
  • Multimodal

Is this molecule toxic? The model looks at it two ways: as a network of atoms and bonds, and as a line of text that describes it. It combines both views to decide. On six standard tests its AUROC score, where 1.0 is perfect, ranges from 0.84 to 0.99.

SFUGAG

  • Python
  • PyTorch
  • PyTorch Geometric
  • Graph neural network

A model trained on one network of data often turns unfair when moved to a new one. This research code adapts the model to the new network without seeing the original data and without any labels, while keeping it fair. Under review at AISTATS.

CanonNet

  • Python
  • Point clouds
  • S3DIS

3D scans come out tilted in random directions. CanonNet turns an object upright using only geometry, with no training, and handles 21 kinds of objects.

I added 208 indoor rooms of 3D scan data (S3DIS) so it can be tried on whole rooms, not just single objects.

SynapseSupply

  • Python
  • Neural networks
  • PostgreSQL
